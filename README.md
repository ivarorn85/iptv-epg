# iptv-epg

A merged XMLTV television guide, rebuilt and re-uploaded twice a day.

This repository holds nothing but the published file. The stable download URL,
which never changes:

```
https://github.com/ivarorn85/iptv-epg/releases/download/epg/guide.xml.gz
```

Add it as an EPG source in TiviMate, Jellyfin, or anything else that reads
XMLTV. The build that produces it lives elsewhere.
